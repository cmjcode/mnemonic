# 🧠 Selamat Datang di Mnemonic!

Mnemonic adalah **vault catatan cerdas** yang menggabungkan kecepatan Google Keep
dengan kedalaman **knowledge management** ala Obsidian — sepenuhnya **offline dan private**.

> [!tip] Semua Data Anda Tetap Lokal
> Tidak ada satu byte pun yang dikirim ke cloud. Catatan Anda adalah file `.md`
> biasa yang bisa dibuka di editor manapun.

## Fitur Utama

Lihat detail di catatan-catatan ini:
- 🔗 [[Proyek Startup AI]] — contoh catatan proyek dengan wikilink bertaut
- ✅ [[Belanja Mingguan]] — checklist interaktif ala Google Keep
- 📊 [[Arsitektur Microservice]] — diagram Mermaid native
- 📚 [[Jurnal Riset NLP]] — pencarian semantik & RAG AI
- 🎯 [[Target 2026]] — catatan pribadi berwarna & pin
- 📐 [[Algoritma Graph]] — canvas whiteboard & block binding
- 📋 [[Meeting Notes Q3]] — notulensi rapat dengan rich formatting
- 🧪 [[Machine Learning 101]] — catatan kuliah terstruktur
- 💡 [[Ide Bisnis]] — brainstorm ide baru
- 🍲 [[Resep Rendang Padang]] — bahkan resep pun bisa jadi knowledge base!
- 🗄️ [[Database Schema]] — desain database dengan ER diagram
- 🤖 Tanya AI di sidebar chat — jawaban dari catatan Anda sendiri (RAG lokal)
- 📑 Buka `proposal-riset.pdf` langsung dari vault
- 📈 Lihat `data-penjualan.csv` sebagai spreadsheet

## Quick Start

- [ ] Buat catatan pertama Anda (Ctrl+N)
- [ ] Coba ketik `[[` untuk autocomplete wikilink
- [ ] Tambahkan tag dengan mengetik `#ide` langsung di teks
- [ ] Buka pencarian semantik (Ctrl+Shift+F)
- [ ] Tanya AI: "Apa saja target Q3?"
- [ ] Buka graph view untuk melihat hubungan antar catatan
- [ ] Coba edit `data-penjualan.csv` sebagai spreadsheet

> [!note] Kompatibilitas Obsidian
> Semua file `.md` di vault ini bisa dibuka langsung di Obsidian, VSCode,
> atau editor teks apapun. Tidak ada lock-in!
